# About This Site

This is a personal portfolio landing page for Chino Concepcion, a Full-Stack Developer based in Cebu, Philippines.

The site presents Chino's work profile, technical focus, project experience, and hiring fit through a modern Angular frontend. It highlights frontend development, backend systems, databases, APIs, Docker deployment, AI workflows, and production-ready implementation.

The page also includes a local AI chat assistant called Chino Agent. The assistant can answer questions about Chino's skills, stack, project experience, and developer profile. It supports text prompts and attachments through a local Node API bridge connected to Ollama.

Main features:

- Angular portfolio landing page
- Responsive hero, profile, skills, and project sections
- Local AI chat widget
- Attachment handling for text, PDF, image, and audio workflows
- Node API bridge for local Ollama chat requests
- Single-container Docker setup for local deployment
